# ❤️ Heart Disease Prediction using Machine Learning

A Streamlit web application that predicts the likelihood of heart disease using Machine Learning. Built with Python, Scikit-learn, and Pandas, it uses the **K-Nearest Neighbors (KNN)** algorithm with feature scaling to generate predictions from patient health parameters.

# Features

-  Heart disease prediction using KNN
-  Feature scaling for data preprocessing
-  Interactive Streamlit interface
-  Real-time predictions

# Tech Stack

- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy

# Installation

```bash
git clone https://github.com/getcloselyai-ctrl/Heart-Disease-Prediction.git
cd Heart-Disease-Prediction
pip install -r requirements.txt
streamlit run app.py
```
